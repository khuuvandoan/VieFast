# 🚀 VieWarp - Next Generation VPN Backend

**VieWarp** là phiên bản Backend tối ưu hóa đặc biệt, được phát triển dựa trên nhân XrayR. Dự án tập trung vào hiệu suất cao, bảo mật tuyệt đối và giao diện quản lý hoàn toàn bằng tiếng Việt cho người dùng Việt Nam.

---

### ✨ Tính năng nổi bật

*   ⚡ **Hiệu suất cực cao:** Tối ưu hóa nhân Xray để giảm độ trễ và tiêu thụ tài nguyên máy chủ.
*   🛡️ **Bảo mật tuyệt đối:** Tích hợp chống scan, ẩn IP máy chủ hiệu quả.
*   🇻🇳 **Giao diện thân thiện:** Menu điều khiển và thông báo 100% bằng tiếng Việt.
*   ⚙️ **Cài đặt siêu tốc:** Chỉ với 1 câu lệnh duy nhất, tự động cấu hình mọi thông số.

---

### 🌐 Giao thức hỗ trợ

VieWarp hỗ trợ đầy đủ các giao thức mạng tiên tiến nhất hiện nay:

| Giao thức | Công nghệ hỗ trợ | Trạng thái |
| :--- | :--- | :--- |
| **VLESS** | Reality, XTLS-vless, TCP, gRPC | ✅ Hoạt động |
| **Shadowsocks** | AEAD, 2022-blake3 | ✅ Hoạt động |
| **VMess** | WebSocket, TCP, KCP | ✅ Hoạt động |
| **Trojan** | TLS, gRPC | ✅ Hoạt động |
| **Hysteria2** | Tối ưu hóa đường truyền | ✅ Hoạt động |
